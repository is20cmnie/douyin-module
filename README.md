# 抖音模块

一个用于抖音的 LSPosed / Xposed 模块，主要功能是让抖音的下载内容**自动按作者、按类型分类存放**，并修复了若干实际使用中的问题。

> 说明：本项目基于在网络上获取的源码进行二次修改，原软件名称为「逗音小手」，原作者信息不详，在此谨向原作者表示感谢。如涉及侵权，请联系删除。

| 项目 | 版本 |
| --- | --- |
| 抖音 | **27.0.0**（仅此版本经过完整实测，其他版本未验证） |

## 相比原版改了什么

### 下载分类（核心改动）
- 下载保存到系统下载目录下，按作者分文件夹：
  `Download/抖音下载/<作者名>/视频`、`.../音频`、`.../图片`
- 评论区的 GIF 表情不按作者分，统一存放在 `Download/抖音下载/表情包`
- 文件名使用**作品 ID** 命名（图集为 `作品ID_序号`）；无 ID 时回退为时间戳
- **重复下载同一个作品会提示「该文件已存在」并跳过**，不会重复占空间；表情包同样按 ID 去重

### 修复：下载下错作品
- 原版在某些入口下会下到别的作品（例如从好友分享链接、搜索结果、作者主页进入视频时，下载的却不是屏幕上这个作品）。已修复为**以屏幕上正在显示的作品为准**，首页滑动、分享链接、搜索、作者主页等入口均已实测正确。

### 其他修正与调整
- 下载时在系统通知栏同步显示进度（v0.02 新增，v0.04 优化文案）：点下载后滑到别的视频也能看到下载百分比和已下载大小；下完或失败时进度通知会被撤掉、另发一条结果通知，完成通知里写的是「作者的视频」而不是看不懂的数字文件名。注：通知借抖音的通知系统发出，标题为「抖音模块」；若抖音的通知被关闭则不会显示
- 评论区长按一张图片时，弹出的面板底部不再混入模块的作品菜单行
- 修复图文作品被误判成视频的问题：按钮错显示「视频下载」、点下去也下不了；现在图文作品会正确显示「图片下载」并按图片保存
- 保存失败时的提示改为简短明确：因缺少文件写入权限失败时，提示「下载失败，请先开启文件写入权限！」
- 删除了已无实际作用的「设置下载保存路径」（保存位置固定为上述目录）
- 默认值调整：「主页添加自动播放按钮」「主页双击打开评论」默认关闭；「标签隐藏」默认除「关注」外全部隐藏
- UI 设置里三个栏（顶部栏 / 底部文案 / 右栏）的透明度调整：修复了切换作品后要等一两秒才生效的延迟
- 模块更名为「抖音模块」，版本号自 0.01 重新计

### 模块自身主页（照原版 v2.1.0 恢复）
- 横幅图片完整显示（原先在 Android 15 上会被顶部标题栏遮挡，已通过调整 targetSdk 修复）
- 中间一行恢复为「当前模块版本」，底部说明恢复为原版文案
- 删除右上角跳转到原作者主页的菜单（该链接已失效）

## 安装与使用

1. 在 [Releases](../../releases) 下载其中的 APK 文件并安装
2. 在 LSPosed 中启用本模块，作用域勾选「抖音」
3. 强行停止抖音后重新打开
4. 在抖音里打开任意作品 → 分享 → 找到模块的功能行（复制链接 / 视频下载 / 音频下载 / UI设置 / 其它设置 / 关于模块）

下载失败时请先确认：系统设置中已给抖音开启「照片和视频 / 文件写入」权限。

## 构建

使用 Gradle 构建（`app/build.gradle.kts`）。签名使用源码自带的公用 keystore，与原版同签，可直接覆盖安装原版。
